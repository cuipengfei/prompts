# Glossary

- **Agentic coding** — coding work delegated to an agent operating with tools and feedback loops. (Ch 13, 18, 25-27)
- **Context engineering** — deliberate selection and maintenance of information supplied to an agent. (Ch 25)
- **Harness engineering** — design of the controls and feedback surrounding an agent. (Ch 26)
- **In-line assistance** — IDE-integrated suggestions while editing code. (Ch 3-4)
- **Local model** — a model operated locally rather than through a remote hosted service. (Ch 28-29)
- **Multi-file editing** — coordinated edits across more than one source file. (Ch 11)
- **Reference application** — a working example used to anchor agent behavior. (Ch 22)
- **Spec-driven development** — using specifications as first-class constraints on implementation. (Ch 23)
