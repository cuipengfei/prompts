# Cheatsheet

- Need an AI coding tool choice: compare task, interaction mode, context assembly, model, hosting.
- Need reliability: add tests, review, deterministic checks, and explicit failure handling.
- Need an autonomous agent: constrain tools, context, permissions, stop conditions, and quality feedback.
- Need a production change: do not rely on prototype success; review maintainability and supply-chain risk.
- Need local models: evaluate real workload, privacy, cost, hardware, and operational friction.
