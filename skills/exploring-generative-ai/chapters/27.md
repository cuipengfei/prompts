# Chapter 27: Humans and Agents in Software Engineering Loops

- **作者**：Kief Morris
- **日期**：2026-03-04
- **来源**：https://martinfowler.com/articles/exploring-gen-ai/humans-and-agents.html

## Core Idea

Human-agent software engineering is a set of feedback loops, not a handoff that eliminates people. Choose where people intervene according to risk, accountability, and the quality of available feedback.

## Oversight Modes

| Mode | Human role | Use when |
|---|---|---|
| **Outside the loop** | Define the desired outcome and let the agent execute the how. | Work is bounded, reversible, and has strong automated checks. |
| **In the loop** | Inspect and steer intermediate work. | Context is incomplete, the task is exploratory, or feedback needs interpretation. |
| **On the loop** | Set controls, monitor outcomes, and intervene on exceptions. | Execution can continue within explicit guardrails and escalation paths. |

Do not choose outside-the-loop execution when impact is high and detectability is low.

## Key Takeaways

1. Design explicit human-agent handoffs and escalation points.
2. Keep accountability visible even when execution is autonomous.
3. Use feedback loops to correct both agents and process.
