# 第 27 章：Humans and Agents in Software Engineering Loops

- **作者**：Kief Morris
- **日期**：2026-03-04
- **来源**：https://martinfowler.com/articles/exploring-gen-ai/humans-and-agents.html

## 核心思想

人机协作的软件工程是一组 feedback loop，不是把人排除掉的手递手交接。按风险、问责与可用反馈的质量，选择人在哪里介入。

## 监督模式

| 模式 | 人的角色 | 何时使用 |
|---|---|---|
| In-the-loop（人在环内） | 在每个动作上审查/批准 | 影响大、可检测性低、需要强问责 |
| On-the-loop（人在环上） | 监督进度与产出，批量审查 | 影响中等，工具可靠，周期检查足够 |
| Outside-the-loop（人在环外） | 审查最终产出 | 风险低、检测可靠、流程稳定 |

影响高且可检测性低时，不要选择 outside-the-loop 执行。

## 要点

1. 显式设计人机交接点与升级点。
2. 即使执行是自主的，也要让问责可见。
3. 用 feedback loop 同时修正 agent 与流程。
