# Chapter 27: Humans and Agents in Software Engineering Loops

- **作者**：Kief Morris
- **日期**：2026-03-04
- **来源**：https://martinfowler.com/articles/exploring-gen-ai/humans-and-agents.html

## Core Idea

Software engineering with agents is a loop of delegation, feedback, review, and human decision-making, not a handoff that eliminates people.

## Key Takeaways

1. Design explicit human-agent handoffs.
2. Keep accountability visible.
3. Use feedback loops to correct both agents and process.
