# Chapter 17: Building Custom Tooling with LLMs

- **作者**：Unmesh Joshi
- **日期**：2025-05-14
- **来源**：https://martinfowler.com/articles/exploring-gen-ai/16-building-custom-tooling-with-llms.html

## Core Idea

Custom LLM tooling should have a clear task boundary, structured inputs and outputs, and deterministic checks around the model.

## Key Takeaways

1. Build tools around a concrete workflow.
2. Keep machine-consumed outputs structured.
3. Make failure handling explicit.
