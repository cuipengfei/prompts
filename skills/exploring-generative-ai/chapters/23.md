# Chapter 23: Understanding Spec-Driven-Development: Kiro, spec-kit, and Tessl

- **作者**：Birgitta Böckeler
- **日期**：2025-10-15
- **来源**：https://martinfowler.com/articles/exploring-gen-ai/sdd-3-tools.html

## Core Idea

Spec-driven development tools make requirements and implementation artifacts more explicit, but their value depends on keeping specifications actionable and connected to verification.

## Key Takeaways

1. Use specs to constrain implementation, not to create paperwork.
2. Keep specs, tasks, and tests aligned.
3. Review tool workflow trade-offs before adopting it.
