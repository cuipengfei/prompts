# 第 7 章：How is GenAI different from other code generators?

- **作者**：Birgitta Böckeler
- **日期**：2023-09-19
- **来源**：https://martinfowler.com/articles/exploring-gen-ai/07-how-is-this-different.html

## 核心思想

GenAI 与传统代码生成器不同，因为它能跨抽象层次提供辅助，而不要求每个期望结果都用形式化模型表达出来。

## 要点

1. 传统生成器用灵活性换取形式化控制。
2. GenAI 能在多个抽象层次上提供帮助。
