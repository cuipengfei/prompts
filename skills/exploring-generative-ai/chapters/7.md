# Chapter 7: How is GenAI different from other code generators?

- **作者**：Birgitta Böckeler
- **日期**：2023-09-19
- **来源**：https://martinfowler.com/articles/exploring-gen-ai/07-how-is-this-different.html

## Core Idea

GenAI differs from traditional code generators because it can assist across abstraction levels without requiring every desired outcome to be expressed in a formal model.

## Key Takeaways

1. Traditional generators trade flexibility for formal control.
2. GenAI can help at multiple abstraction levels.
3. Flexibility does not remove the need for human judgment.
