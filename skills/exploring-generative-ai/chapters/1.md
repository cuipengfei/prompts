# 第 1 章：The toolchain

- **作者**：Birgitta Böckeler
- **日期**：2023-07-26
- **来源**：https://martinfowler.com/articles/exploring-gen-ai/01-tool-landscape.html

## 核心思想

把 LLM 辅助编码看作一条工具链：任务、交互模式、prompt 构成、模型属性与托管方式都会影响结果。

## 核心概念

- **辅助任务（Assisted tasks）**：查找信息、生成代码、推理代码、转换代码。
- **交互模式（Interaction mode）**：chat、IDE 内联辅助或 CLI 交互。
- **Prompt 构成（Prompt composition）**：用户输入加上工具选择的 context，可以塑造一次请求。

## 要点

1. 不要只按模型名称比较工具。
2. 按任务与 feedback loop 选择工具链。
