# Chapter 1: The toolchain

- **作者**：Birgitta Böckeler
- **日期**：2023-07-26
- **来源**：https://martinfowler.com/articles/exploring-gen-ai/01-tool-landscape.html

## Core Idea

View LLM-assisted coding as a toolchain: task, interaction mode, prompt composition, model properties, and hosting all affect the result.

## Key Concepts

- **Assisted tasks**: finding information, generating code, reasoning about code, and transforming code.
- **Interaction mode**: chat, in-line IDE assistance, or CLI interaction.
- **Prompt composition**: user input plus tool-selected context can shape a request.

## Key Takeaways

1. Do not compare tools only by model name.
2. Choose a toolchain for the task and feedback loop.
3. Treat context selection as a product capability and risk.
