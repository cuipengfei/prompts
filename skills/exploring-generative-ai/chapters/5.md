# 第 5 章：Coding assistants do not replace pair programming

- **作者**：Birgitta Böckeler
- **日期**：2023-08-10
- **来源**：https://martinfowler.com/articles/exploring-gen-ai/05-not-your-pair-programmer.html

## 核心思想

Coding assistant 能支持战术性工作，但提供不了结对编程的沟通、共同学习、专注与团队实践收益。

## 要点

1. 不要把「生成建议」等同于「结对」。
2. 保留人工协作，用于知识交换与反馈。
