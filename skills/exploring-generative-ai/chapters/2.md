# Chapter 2: Median - A tale in three functions

- **作者**：Birgitta Böckeler
- **日期**：2023-07-27
- **来源**：https://martinfowler.com/articles/exploring-gen-ai/02-median-tale.html

## Core Idea

A small median-function exercise illustrates both the speed and the limits of LLM-assisted coding: suggestions still need specification, inspection, and tests.

## Key Takeaways

1. A plausible implementation is not a verified implementation.
2. Small examples expose ambiguity in requirements and edge cases.
3. Use generated code as a starting point for a feedback loop.
