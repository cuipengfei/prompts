# 第 19 章：I still care about the code

- **作者**：Birgitta Böckeler
- **日期**：2025-07-09
- **来源**：https://martinfowler.com/articles/exploring-gen-ai/i-still-care-about-the-code.html

## 核心思想

AI 辅助开发仍让人类对持久化的代码负责。因为生成输出仍是非确定性的，风险评估必须先于信任程度与 review 强度。

## 风险评估

三个维度一起评估：

- **Probability（出错概率）**：任务、工具、模型与 context 的组合出错的可能性。
- **Impact（影响）**：错误在到达用户之前能扩散多远、破坏多大。
- **Detectability（可检测性）**：检查或 review 在伤害之前抓到问题的可能性。

高影响加低可检测性，即使输出看似合理，也需要强人工审查。

## 要点

1. 把代码当作持久产品来 review，而不只是生成的输出。
2. 当概率无法降到零时，保持设计与质量标准明确。
3. 在高影响、低可检测性的工作中，不要用理解换取短期生成速度。
