# Chapter 19: I still care about the code

- **作者**：Birgitta Böckeler
- **日期**：2025-07-09
- **来源**：https://martinfowler.com/articles/exploring-gen-ai/i-still-care-about-the-code.html

## Core Idea

AI-assisted development does not make code quality, maintainability, and human responsibility irrelevant.

## Key Takeaways

1. Review code as an enduring product, not merely generated output.
2. Keep design and quality standards explicit.
3. Do not trade understanding for short-term generation speed.
