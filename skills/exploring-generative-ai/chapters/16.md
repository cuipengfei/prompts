# Chapter 16: Coding Assistants Threaten the Software Supply Chain

- **作者**：Jim Gumbley、Lilly Ryan
- **日期**：2025-05-13
- **来源**：https://martinfowler.com/articles/exploring-gen-ai/software-supply-chain-attack-surface.html

## Core Idea

Coding assistants can introduce software-supply-chain risk; generated dependencies, scripts, and instructions require the same security scrutiny as other external inputs.

## Anti-patterns

- Treating generated package or command suggestions as trusted.
- Skipping provenance, dependency, and permission review.
