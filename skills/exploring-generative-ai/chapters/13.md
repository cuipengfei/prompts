# 第 13 章：The role of developer skills in agentic coding

- **作者**：Birgitta Böckeler
- **日期**：2025-03-25
- **来源**：https://martinfowler.com/articles/exploring-gen-ai/13-role-of-developer-skills.html

## 核心思想

开发者 skill 把反复出现的判断、约束与工作流外化，让 agent 不必依赖临时拼凑的 prompt。当失误的影响超出单次局部编辑时，它们最重要。

## 影响半径

按失误何时变得可见来给反复出现的 agent 失败分类：

- **单次编辑**：失误在写入文件时即可见。
- **提交或合并**：失误在集成或 CI 时才可见。
- **团队迭代**：失误在数天后其他成员遇到时才可见。
- **Codebase 生命周期**：失误要数月才暴露，由维护者承担代价。

半径越大，feedback loop 越长，预防性指导就该越强。

## 要点

1. 把可重复的判断与工作流约束放进可复用的 skill。
2. 每个 skill 的范围要对应一个可识别的决策或失败模式。
3. 用观察到的失败，而不是假设性的建议，来决定什么该进 skill。
