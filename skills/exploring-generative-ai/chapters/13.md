# Chapter 13: The role of developer skills in agentic coding

- **作者**：Birgitta Böckeler
- **日期**：2025-03-25
- **来源**：https://martinfowler.com/articles/exploring-gen-ai/13-role-of-developer-skills.html

## Core Idea

Developer skills externalize recurring judgment, constraints, and workflow so agents do not rely on an improvised prompt. They matter most when a misstep's impact reaches beyond a single local edit.

## Impact Radius

Classify recurring agent failures by when they become visible:

| Radius | Signal | Response |
|---|---|---|
| **Time to commit** | The agent slows a local task or produces obviously wrong output. | Improve task framing or discard the attempt. |
| **Team iteration** | The change enters shared work and creates rework or coordination cost. | Add shared conventions, review checks, or reusable instructions. |
| **Codebase lifetime** | The change creates maintainability, architecture, or security debt. | Encode durable constraints in a skill, specification, or harness control. |

The larger the radius, the longer the feedback loop and the stronger the preventative guidance should be.

## Key Takeaways

1. Put repeatable judgment and workflow constraints in reusable skills.
2. Keep each skill scoped to a recognizable decision or failure pattern.
3. Use observed failures, not hypothetical advice, to decide what belongs in a skill.
