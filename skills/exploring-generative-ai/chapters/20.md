# Chapter 20: Partner with the AI, throw away the code

- **作者**：Matteo Vaccari
- **日期**：2025-07-31
- **来源**：https://martinfowler.com/articles/exploring-gen-ai/partner-with-ai-and-throw-away-the-code.html

## Core Idea

Use AI to explore and learn quickly, while retaining the freedom to discard exploratory output when it does not meet the required standard.

## Key Takeaways

1. Separate exploration from production code.
2. Discard weak output rather than rationalizing it.
3. Keep the human accountable for the final design.
