# Chapter 26: Harness Engineering - first thoughts

- **作者**：Birgitta Böckeler
- **日期**：2026-02-17
- **来源**：https://martinfowler.com/articles/exploring-gen-ai/harness-engineering-memo.html

## Core Idea

The harness around an agent—tools, instructions, feedback, and controls—shapes outcomes as much as the underlying model.

## Key Takeaways

1. Engineer the surrounding workflow, not only prompts.
2. Put deterministic controls around risky behavior.
3. Improve the harness from observed failures.
