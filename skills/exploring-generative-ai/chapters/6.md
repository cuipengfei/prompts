# Chapter 6: TDD with GitHub Copilot

- **作者**：Paul Sobocinski
- **日期**：2023-08-17
- **来源**：https://martinfowler.com/articles/exploring-gen-ai/06-tdd-with-coding-assistance.html

## Core Idea

TDD remains valuable with coding assistants because LLM output is unreliable and iterative feedback helps decompose work into solvable, checkable steps.

## Key Takeaways

1. Tests provide fast feedback on generated code.
2. Divide-and-conquer remains useful for AI-assisted work.
3. Use failing tests to constrain the next suggestion.
