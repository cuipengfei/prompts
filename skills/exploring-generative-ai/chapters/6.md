# 第 6 章：TDD with GitHub Copilot

- **作者**：Paul Sobocinski
- **日期**：2023-08-17
- **来源**：https://martinfowler.com/articles/exploring-gen-ai/06-tdd-with-coding-assistance.html

## 核心思想

有了 coding assistant，TDD 依然有价值，因为 LLM 输出不可靠，而迭代式反馈有助于把工作拆解成可解决、可检查的步骤。

## 要点

1. 测试为生成的代码提供快速反馈。
2. 分而治之对 AI 辅助工作仍然有用。
