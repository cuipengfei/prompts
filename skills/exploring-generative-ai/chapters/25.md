# Chapter 25: Context Engineering for Coding Agents

- **作者**：Birgitta Böckeler
- **日期**：2026-02-05
- **来源**：https://martinfowler.com/articles/exploring-gen-ai/context-engineering-coding-agents.html

## Core Idea

Coding-agent performance depends on deliberately selecting, structuring, and maintaining the context it receives.

## Key Takeaways

1. Supply task-relevant context rather than maximum context.
2. Preserve durable constraints and remove stale noise.
3. Treat context design as an engineering concern.
