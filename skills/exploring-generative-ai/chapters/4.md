# Chapter 4: In-line assistance - how can it get in the way?

- **作者**：Birgitta Böckeler
- **日期**：2023-08-03
- **来源**：https://martinfowler.com/articles/exploring-gen-ai/04-coding-assistance-how-in-the-way.html

## Core Idea

Assistants can amplify bad or outdated repository examples because their context selection cannot distinguish sound practices from weak ones.

## Anti-patterns

- **Poisoned context**: stale or poor examples bias suggestions toward the wrong pattern.
- Trusting a context-aware suggestion without reviewing its design quality.

## Key Takeaways

1. Improve repository examples and context before trusting suggestions.
2. Review generated code independently.
3. New conventions need explicit reinforcement while old examples remain common.
