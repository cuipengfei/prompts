# Chapter 10: Building an AI agent application to migrate a tech stack

- **作者**：Birgitta Böckeler
- **日期**：2024-08-20
- **来源**：https://martinfowler.com/articles/exploring-gen-ai/10-ai-for-tech-stack-migration.html

## Core Idea

Tech-stack migration is a promising agent use case, but the agent must understand a concrete sequence of actions and the migration outcome must be verified.

## Key Takeaways

1. Define migration steps and observable success criteria.
2. Treat agent actions as an implementation workflow, not magic.
3. Review conversions for semantic correctness.
