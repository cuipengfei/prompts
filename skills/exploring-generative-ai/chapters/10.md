# 第 10 章：Building an AI agent application to migrate a tech stack

- **作者**：Birgitta Böckeler
- **日期**：2024-08-20
- **来源**：https://martinfowler.com/articles/exploring-gen-ai/10-ai-for-tech-stack-migration.html

## 核心思想

技术栈迁移是很有前景的 agent 用例，但 agent 必须理解具体的动作序列，而且迁移结果必须经过验证。

## 要点

1. 定义迁移步骤与可观察的成功标准。
2. 把 agent 的动作当作实现工作流，而不是魔法。
