# Chapter 11: Expanding the solution size with multi-file editing

- **作者**：Birgitta Böckeler
- **日期**：2024-11-19
- **来源**：https://martinfowler.com/articles/exploring-gen-ai/11-multi-file-editing.html

## Core Idea

Multi-file editing changes the practical size of tasks an assistant can help implement, but it increases the need to inspect, constrain, and review cross-file changes.

## Key Takeaways

1. Use multi-file editing for a bounded, understood change rather than a vague rewrite.
2. Review the full change set, not only the file that prompted the edit.
3. Keep tests and repository conventions as constraints on generated edits.
