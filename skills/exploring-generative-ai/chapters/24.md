# Chapter 24: Assessing internal quality while coding with an agent

- **作者**：Erik Doernenburg
- **日期**：2026-01-27
- **来源**：https://martinfowler.com/articles/exploring-gen-ai/ccmenu-quality.html

## Core Idea

Agent-assisted coding needs feedback about internal quality, not only whether a feature appears to work.

## Key Takeaways

1. Add quality signals to the agent feedback loop.
2. Measure maintainability alongside functional checks.
3. Use findings to guide the next change.
