# 第 29 章：Experiences with local models for coding

- **作者**：Birgitta Böckeler
- **日期**：2026-07-08

## 核心思想

本地编码模型的可行性是一个漏斗：在把时间花在复杂 agent 任务之前，先通过更便宜的前置条件。能回答 prompt 的模型，在编码 harness 内不一定可行。

## Viability Funnel（可用性漏斗）

1. **内存适配**：确认模型权重与所需 context 装得进可用 RAM 或 VRAM。
2. **达到可用速度**：评估 agent 工作流之前，先跑一个简单请求。
3. **正确使用工具**：确认模型在真实工具调用中可靠，而不只是示例中。
4. **保持正确**：验证事实与代码正确性，不只是流畅度。
5. **处理真实 context**：只有内存与速度都通过后，才测试大的 context 加载。
6. **处理任务规模**：更早阶段通过后，再增加探索、文件数量与复杂度。
7. **保持 review 负担可接受**：把编码速度与所需 review 和修正工作量比较。

## 要点

1. 在有代表性的任务中测试模型，而不是 chat-only prompt。
2. 在第一个失败阶段记录失败模式与运营摩擦。
3. 用实测证据细化模型选择决策，让任务保持在已验证的极限内。
