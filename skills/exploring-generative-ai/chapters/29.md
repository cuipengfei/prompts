# Chapter 29: Experiences with local models for coding

- **作者**：Birgitta Böckeler
- **日期**：2026-07-08
- **来源**：https://martinfowler.com/articles/exploring-gen-ai/local-models-for-coding-experiences.html

## Core Idea

Local coding-model viability is a funnel: pass cheaper prerequisites before spending time on complex agent tasks. A model that can answer a prompt is not necessarily viable inside a coding harness.

## Viability Funnel

1. **Fit memory**: confirm model weights and required context fit available RAM or VRAM.
2. **Reach usable speed**: run a simple request before evaluating an agent workflow.
3. **Handle tool calling**: verify file-reading and file-changing calls in the harness.
4. **Produce functionally correct code**: use a bounded representative task with checks.
5. **Sustain context**: continue the conversation long enough to expose context limits.
6. **Handle task size**: increase discovery, file count, and complexity only after earlier stages pass.
7. **Keep review burden acceptable**: compare coding speed against required review and correction effort.

## Key Takeaways

1. Test models in representative tasks, not chat-only prompts.
2. Record failure modes and operational friction at the first failed stage.
3. Use experience evidence to refine model-selection decisions and keep tasks within demonstrated limits.
