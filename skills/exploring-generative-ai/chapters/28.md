# Chapter 28: Viability of local models for coding

- **作者**：Birgitta Böckeler
- **日期**：2026-07-07

## Core Idea

Local-model viability for coding is a systems decision: capability, privacy, cost, hardware, context capacity, and harness behavior all matter. A benchmark or one successful prompt is not enough.

## Evaluation Factors

- **Memory fit**: model weights and working context must fit available RAM or VRAM.
- **Processing speed**: response speed must sustain the intended interactive or agent workflow.
- **Tool calling**: agentic coding needs reliable tool invocation and recovery from failures.
- **Task and stack fit**: evaluate representative languages, task sizes, and repository shapes.
- **Operational constraints**: include privacy, cost, quantization, hosting, and review effort.

## Key Takeaways

1. Evaluate local models against the real workflow, not a generic benchmark.
2. Include hardware and operational constraints in the decision.
3. Compare capability and control together, then continue to the practical funnel in Ch 29.
