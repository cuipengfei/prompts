# 第 28 章：Viability of local models for coding

- **作者**：Birgitta Böckeler
- **日期**：2026-07-07
- **来源**：https://martinfowler.com/articles/exploring-gen-ai/local-models-for-coding-factors.html

## 核心思想

本地模型用于编码的可行性是一个系统决策：能力、隐私、成本、硬件、context 容量与 harness 行为都重要。一个 benchmark 或一次成功的 prompt 不够。

## 评估因素

- **内存适配（Memory fit）**：模型权重与工作 context 必须装进可用 RAM 或 VRAM。
- **处理速度**：响应速度必须支撑预期的交互或 agent 工作流。
- **任务与技术栈匹配**：评估有代表性的语言、任务规模与仓库形态。
- **运营约束**：包括隐私、成本、量化、托管与 review 工作量。

## 要点

1. 对照真实工作流评估本地模型，而不是通用 benchmark。
2. 决策中包含硬件与运营约束。
3. 能力与控制一起比较，然后进入第 29 章的实用漏斗。
