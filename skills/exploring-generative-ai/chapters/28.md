# Chapter 28: Viability of local models for coding

- **作者**：Birgitta Böckeler
- **日期**：2026-07-07
- **来源**：https://martinfowler.com/articles/exploring-gen-ai/local-models-for-coding-factors.html

## Core Idea

Whether local models are viable for coding depends on task quality, hardware, privacy, cost, and workflow constraints rather than a single benchmark.

## Key Takeaways

1. Evaluate local models against the real workflow.
2. Include operational constraints in the decision.
3. Compare capability and control together.
