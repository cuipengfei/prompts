# 第 18 章：Autonomous coding agents: A Codex example

- **作者**：Birgitta Böckeler
- **日期**：2025-06-04
- **来源**：https://martinfowler.com/articles/exploring-gen-ai/autonomous-agents-codex-example.html

## 核心思想

自主编码 agent 需要执行环境、工具、约束与 feedback loop；自主性并不消除任务框定与 review 的必要性。

## 要点

1. 给 agent 有边界的目标与可观察的完成检查。
2. 检查工具使用与产生的 diff。
