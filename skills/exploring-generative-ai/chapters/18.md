# Chapter 18: Autonomous coding agents: A Codex example

- **作者**：Birgitta Böckeler
- **日期**：2025-06-04
- **来源**：https://martinfowler.com/articles/exploring-gen-ai/autonomous-agents-codex-example.html

## Core Idea

Autonomous coding agents need an execution environment, tools, constraints, and feedback loops; autonomy does not remove the need for task framing and review.

## Key Takeaways

1. Give agents bounded goals and observable completion checks.
2. Inspect tool use and resulting diffs.
3. Escalate high-impact actions instead of making them implicit.
