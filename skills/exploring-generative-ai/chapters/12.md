# Chapter 12: What role does LLM reasoning play for software tasks?

- **作者**：Birgitta Böckeler
- **日期**：2025-02-18
- **来源**：https://martinfowler.com/articles/exploring-gen-ai/12-role-of-reasoning.html

## Core Idea

Reasoning-oriented models can improve some software tasks, but task decomposition, feedback, and verification still determine whether their output is useful.

## Key Takeaways

1. Match model capability to task shape.
2. Prefer observable checks over confidence in a rationale.
3. Treat reasoning output as input to review, not proof of correctness.
