# Chapter 22: Anchoring AI to a reference application

- **作者**：Birgitta Böckeler
- **日期**：2025-09-25
- **来源**：https://martinfowler.com/articles/exploring-gen-ai/anchoring-to-reference.html

## Core Idea

A reference application gives an AI concrete conventions and examples, reducing ambiguity in generated changes.

## Key Takeaways

1. Prefer relevant working examples over abstract instructions.
2. Keep reference material current and scoped.
3. Validate generated changes against the reference’s intended conventions.
