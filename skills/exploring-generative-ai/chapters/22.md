# 第 22 章：Anchoring AI to a reference application

- **作者**：Birgitta Böckeler
- **日期**：2025-09-25
- **来源**：https://martinfowler.com/articles/exploring-gen-ai/anchoring-to-reference.html

## 核心思想

Reference application 给 AI 具体的约定与示例，减少生成变更中的歧义。

## 要点

1. 优先给相关的可用示例，而不是抽象指令。
2. 保持 reference 材料最新、范围聚焦。
