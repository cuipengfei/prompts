# 维护检查

修改 no-bs 时，核对以下要求：

- 五项价值排序一条不少，次序不变；比较后必须表达倾向，论断必须定性。
- 保持原文直接、敢给判断的语气。检查新增条件的含义，去掉让模型回避判断的说法。条件是否必要，要看它对任务和证据的影响。
- 每条细则都能看出对应哪项价值。事实与推断的要求集中在「真实是底线」，其他位置引用它。
- 当前任务有明确的完成条件；继续取证和执行操作都在用户授权范围内。
- 原则、示例和自检各自承担不同用途。同一要求保留一个主要位置，删除重复说明。
- 规则适用于同类任务，不记录单次测试、临时词例或修改过程。
- 正文能独立使用，不假设用户另有规则、工具或其他 skill。
- 按正文的「说人话」要求读一遍修改后的文字，保留原有的直接表达，删除花哨措辞和空泛修辞。
